MmasiEjikeme Studios — Public site on mobile

The same public site drawn on a 390×844 phone, because most WhatsApp inquiries begin on one. Scrolling pages are .webframe.ph.narrow; the viewport-locked states — the full-screen menu, the lightbox, the player, a shared link — are fixed .phone.narrow frames.

Mobile excellence is a requirement, not a reduction. Every button is thumb-sized, the gallery drops to two columns, the lightbox stacks the image over its spec card, and the reel player fills the screen. The header collapses to a monogram, a theme toggle and a hamburger; the nav lives in the full-screen pub-m-menu drawer.
Each frame here answers a desktop frame of the same name on 01-public-desktop.html; the sids are prefixed pub-m- so the manifest counts both.
