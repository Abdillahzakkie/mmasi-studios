MmasiEjikeme Studios — Studio admin contact sheet

Ten frames of the studio admin: the fixed app shell MmasiEjikeme signs into to keep the portfolio current, read the inquiries the public site routes in, and share any photograph or reel with a client. Every frame is drawn at 1440 × 900 in the editorial light theme — the admin never carries the cinematic dark — laid out as a 236px rail beside a pane.

The admin exists so the work stays current without a developer. A new photograph or reel is added here, a caption is fixed here, and an inquiry moves from New to Booked here. Every piece carries a one-click share that opens WhatsApp with the client, so a conversation starts from the studio's own screen in seconds.

Vocabulary is frozen. Every frame is drawn in design/mockups/system.css and invents no class, colour or type size of its own. WhatsApp is +234 814 709 9175; the share and reply actions open it in .btn.wa green. Status is a word and a colour together, never a colour alone.

WEB ONLY. No admin frame is ever built on the phone. The studio curates from a desk — a portfolio table read row by row, a photograph edited beside its live preview, an inquiry opened to its full vision. The public site is where a client books on their phone; the admin is where the studio answers from a laptop.

Access

One shared studio sign-in. The whole team works from a single account, so the card names the studio, not a person.

Portfolio

The photographs and reels the public site reads, the forms that add or fix one, the share dialog that sends a piece to a client, and what the studio sees on day one before a single frame is uploaded.

Inquiries

The conversations the public site routes in from WhatsApp: the list the studio triages, and one inquiry opened to its full detail — including one a client sent with no project vision written.

Settings

The studio profile the public site reads back: the WhatsApp number every booking button opens, the display coordinates, and the social channels.
